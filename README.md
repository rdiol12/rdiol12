I build native, controller-first applications and the systems around them: device pairing, persistent jobs, media-rich interfaces, reproducible builds, and hardware-aware testing.

## Featured work

### [PS5Library](https://github.com/rdiol12/PS5Library)

A native, controller-first storefront for a self-hosted PS5 library, with a C++ console frontend, Swift companion source, automated builds, and console-side tooling.

### [OpenStory](https://github.com/rdiol12/OpenStory)

A modern C++ resurrection of the v83 MapleStory client for Cosmic servers, including OpenGL rendering, gamepad support, spatial audio, Unicode input, and right-to-left text.

### [Diabetes Data Analysis](https://github.com/rdiol12/diabetes-data-analysis)

An end-to-end notebook covering data cleaning, statistical testing, K-Means clustering, and PCA across 4,500 validated records.

### [SmartCart](https://github.com/rdiol12/SmartCartApp)

A JavaScript smart-shopping-list application.
